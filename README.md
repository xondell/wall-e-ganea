# WALL-E — интерактивная презентация для Ganea Group

**Дата подготовки:** 25.10.2026  
**Назначение:** встреча Бориса Колесова с Игорем Ганей, 9:00, 25 октября 2026 года (по сообщению Бориса).  
**Аудитория:** собственник бизнеса и потенциальная инженерная команда.  
**Продолжительность выступления:** 7–10 минут + вопросы.  
**Формат:** автономная веб-презентация, 12 слайдов, без внешних JavaScript/CDN/API.

## Открыть презентацию

1. Распакуйте ZIP.
2. Откройте **`index.html`** в Chrome, Firefox или другом современном браузере. Интернет не нужен.
3. Нажмите **F** для полноэкранного режима; используйте **← / →** для переключения.

Второй вариант — локально в папке проекта:

```bash
python3 -m http.server 8765
```

Затем `http://localhost:8765/`. Отдельная сборка и npm не требуются.

## Получить настоящие скриншоты всех слайдов

На Linux с установленным Google Chrome или Chromium выполни из распакованной папки:

```bash
bash capture-slides.sh
```

Скрипт последовательно откроет `index.html#1` … `#12` **локально** в headless Chrome, сохранит 12 PNG и создаст `WALL_E_SLIDES_SCREENSHOTS_1920x1080.zip`. Интернет и передача содержимого в облако не требуются. Если Chrome не установлен — скрипт сообщит об этом; ничего не устанавливает самостоятельно.

## Важные разграничения

**Сделано:** исследование, архитектурная постановка задачи, независимый аудит, ТЗ для разработчика цифрового прототипа, эта презентация.

**Ещё не сделано:** работающая физическая симуляция в Gazebo, конструкция с проверенной механикой рамки, производственный CAD, реальный прототип и полевые испытания.

Вращаемые модели в презентации созданы процедурным JS-рендерером **как визуализация концепции**. Это **не** Gazebo, CAD, техническая симуляция или результат испытаний. Параметры слайда «Цифровая лаборатория» меняют вид условной иллюстрации, не рассчитывают физику. Фактические значения массы, трения, геометрии и силы прополиса не измерены.

**Про токены:** Борис оценил затраты на подготовку WALL-E приблизительно в 60 млн AI-токенов. На приложенном оригинальном скрине панели GLM за выбранные 7 дней видно **82,5 млн суммарно** (GLM-5.3: 45 млн; GLM-5.3-Flash: 37,5 млн). Скрин не разделяет задачи WALL-E и другие задачи, поэтому не может служить независимым доказательством точного расхода на проект. Кнопка «Увеличить скрин» на слайде 9 показывает оригинал; также файл лежит в `assets/`.

Цель «1 сотрудник на 1000 ульев за 12 месяцев» и нынешние «3–4 на 1000» взяты из предварительного обсуждения, не из проверенного кадрового учёта. Это цель/гипотеза, не обещание результата.

## Публикация

Проект готов для статического хостинга, включая GitHub Pages. **Ничего не опубликовано автоматически**, и никакие материалы Ganea не загружались на сторонние серверы.

Workflow `.github/workflows/pages.yml` формирует отдельную публичную папку `site` только из HTML, CSS, JavaScript и скрина GLM; **не** публикует README, исследования, рабочие файлы и скрипты как страницы. При этом исходные файлы самого **публичного репозитория** всё равно будут видны всем.

Включён скрипт `deploy-pages.sh`: по умолчанию показывает инструкцию **без публикации**. Только явный запуск `bash deploy-pages.sh --publish OWNER/REPO` с дополнительным текстовым подтверждением создаёт/обновляет **публичный** репозиторий, включает GitHub Pages через API и запускает GitHub Actions. Уже существующий репозиторий без связанной локальной Git-истории скрипт менять отказывается. Нужно установить `git` и `gh`, авторизоваться через `gh auth login`. Перед запуском убедись, что имеешь право публично показывать детали проекта и сам скрин аккаунта GLM. Ничего не публиковалось в ходе подготовки этого архива.
