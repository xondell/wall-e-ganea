# WALL-E — интерактивная презентация для Ganea Group

**Дата подготовки:** 25.10.2026  
**Назначение:** встреча Бориса Колесова с Игорем Ганей, 9:00, 25 октября 2026 года (по сообщению Бориса).  
**Аудитория:** собственник бизнеса и потенциальная инженерная команда.  
**Продолжительность выступления:** 7–10 минут + вопросы.  
**Формат:** автономная веб-презентация, 11 слайдов, без внешних JavaScript/CDN/API.

## Открыть презентацию

1. Распакуйте ZIP.
2. Откройте **`index.html`** в Chrome, Firefox или другом современном браузере. Интернет не нужен.
3. Нажмите **F** для полноэкранного режима; используйте **← / →** для переключения.

Второй вариант — локально в папке проекта:

```bash
python3 -m http.server 8765
```

Затем `http://localhost:8765/`. Отдельная сборка и npm не требуются.

9. Ориентировочная дорожная карта на 12 месяцев.
10. Что нужно от Ganea и какие решения принять.
11. Источники и оговорки.

## Важные разграничения

**Сделано:** исследование, архитектурная постановка задачи, независимый аудит, ТЗ для разработчика цифрового прототипа, эта презентация.

**Ещё не сделано:** работающая физическая симуляция в Gazebo, конструкция с проверенной механикой рамки, производственный CAD, реальный прототип и полевые испытания.

Вращаемые модели в презентации созданы процедурным JS-рендерером **как визуализация концепции**. Это **не** Gazebo, CAD, техническая симуляция или результат испытаний. Параметры слайда «Цифровая лаборатория» меняют вид условной иллюстрации, не рассчитывают физику. Фактические значения массы, трения, геометрии и силы прополиса не измерены.

Цель «1 сотрудник на 1000 ульев за 12 месяцев» и нынешние «3–4 на 1000» взяты из предварительного обсуждения, не из проверенного кадрового учёта. Это цель/гипотеза, не обещание результата.

## Публикация

Проект готов для статического хостинга, включая GitHub Pages. **Ничего не опубликовано автоматически**, и никакие материалы Ganea не загружались на сторонние серверы.

Для будущего GitHub Pages можно включить workflow `.github/workflows/pages.yml` после согласования репозитория и публичности. Установить в Settings → Pages → Source: GitHub Actions. Он публикует только содержимое этой папки.

Включён осторожный скрипт `deploy-pages.sh`: по умолчанию показывает инструкцию **без публикации**. Только явный запуск `bash deploy-pages.sh --publish OWNER/REPO` с дополнительным текстовым подтверждением создаёт/обновляет **публичный** репозиторий через GitHub CLI. Не используйте без разрешения Ganea на публикацию материалов.
